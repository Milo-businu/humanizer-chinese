# 包袱版 Skill 提案

> 基于通用版「白描改写」扩展。本提案只做设计，不含实现代码。

## 〇、定位自洽：家族里唯一的「增味版」

通用版和前四版都做**减味/调味**：学术版去套话、营销版去自夸、文学版去套路、社媒版去假人味。包袱版不同——它要**主动造笑**，是家族里唯一「增味」的版本。

这不冲突，但要把家族不变量重新说清楚：

- **共享底线**：事实不变、人物动机不变、红线不破。
- **共享工作流**：标记 → 出初稿 → 核对 → 终稿。
- **各自目标**：前四版让文字「像人说」，包袱版让文字「该笑的地方真的笑」。
- **家族表述**：通用版与前四版做表达层的减味/调味，包袱版做表达层的增味——但增的是**结构**（铺垫—违背—良性解释—回收），不是往事实里掺水。

## 一、版本定位

**一句话**：在事实、人设与红线不变的前提下，诊断并重构「铺垫—违背—良性解释—回收」结构与节奏，把尬包袱、闷包袱改成「意料之外、情理之中」的响包袱，并按载体（相声/脱口秀/小品/书面段子/短视频）调停顿、调语域、调分寸。

**核心原则**：通用版是「意思不变，话变」；包袱版升级为「**意思不变、动机不变、红线不破，笑点结构重建**」。笑点只能加在表达层，不能靠扭曲事实或让人物做违背设定的行为来换笑。

**底层公式**（学术共识）：幽默 = 违背（Violation）+ 良性解释（Benign）。必须同时成立——预期被打破，且这个打破被判定为无害、善意。

## 二、适用场景

- 脱口秀段子的 setup / punchline / tag 打磨
- 相声、小品、情景喜剧的包袱设计（三翻四抖、铺平垫稳、伏笔回收）
- 短视频段子的前 2 秒钩子与反转
- 书面幽默：段子、专栏、评论区、文学喜剧
- 幽默广告（与营销版协同，笑点不得压过卖点）
- 已有笑话的诊断：为什么不好笑、哪里尬

## 三、目标用户

- 脱口秀演员、喜剧编剧
- 相声/小品创作者
- 短视频段子手、内容创作者
- 写幽默专栏、段子的作者
- 想让文案更有幽默感的营销人

## 四、核心能力

1. **包袱诊断**：判断一个笑话为什么不响——解释笑话、铺垫泄底、节奏均匀、双关生硬、老梗反刍、笑点后补解释。
2. **结构重构**：按「铺垫 — 违背 — 良性解释 — 回收」重建；需要时用 rule of three、callback、running gag、tag 等技法。
3. **节奏标记**：按载体给停顿、冷脸、语速反差提示；书面载体用标点、分段、换行制造视觉停顿。
4. **载体适配**：相声/脱口秀/小品/书面段子/短视频各有不同结构与验收标准，先识别再改。
5. **人设守门**：每个角色有固定笑法，不为抖包袱让人物行为失真。
6. **红线检查**：攻击方向矩阵（自嘲 > punching up > punching down 禁止）、灾难/弱势/歧视/低俗禁区。
7. **老梗识别**：识别被用滥的梗与老梗变体，提示原创性风险。

## 五、内容与风格规范

### 5.1 包袱版专属病灶

| # | 病灶 | 改写前 | 改写后 |
|---|------|--------|--------|
| J1 | 解释笑话 | ……但我的老板不配。也就是说，我是在用反讽表达对职场关系的不满，懂了吧？ | 揭底即止：「……但我的老板不配。」然后闭嘴 |
| J2 | 反笑话（有期待无包袱） | 为什么鸡要过马路？因为它想去另一边。 | 建起期待后必须给出违背；没包袱就别用设问 |
| J3 | 老梗反刍 | 为什么数学书不开心？因为它有太多 problems。 | 标记「老梗」，要求换成源自当下语境的新观察 |
| J4 | 铺垫泄底（Telegraphing） | 我跟你说个特别好笑的事啊…… | 铺垫要像大实话一样正经；别提前提示「我要搞笑了」 |
| J5 | 铺垫过长/过短 | 先 200 字交代物业邻居快递柜品牌，才说忘了密码 | 铺垫短、清楚、像一句真话；没有铺垫就没有包袱 |
| J6 | 节奏均匀、该停没停 | 我也想努力工作啊但我的老板不配。（一口气读完） | 我也想努力工作啊……（停顿）……但我的老板不配。 |
| J7 | Tag 不短、揭底后啰嗦 | 主包袱后又补一大段解释原因 | Tag 越说越短、越说越快；揭底后多说即抢笑声 |
| J8 | 强行谐音、双关生硬（**不含冷笑话/无语式谐音**） | 在非冷笑话语境里硬塞谐音，两层语义都不贴合，听者只觉尴尬而非无语地笑 | 先判断语境：冷笑话里「尬」就是笑点，保留（见场景 2）；只有语义两层都不成立、又不走无语路线的谐音才是病灶 |
| J9 | 为反转而反转、逻辑不通 | 我迟到是因为穿越到了昨天，然后全场大笑 | 荒谬必须有内部逻辑；角色可有一套坚信的歪理 |
| J10 | 人物为抖包袱行为失真 | 全程克制的人突然无铺垫当众大喊「我就是个废物哈哈哈」 | 角色行动须有内驱力；笑点要符合人物当时处境 |
| J11 | 网络老梗堆砌/伪反应 | 这操作太离谱了，笑死，笑不活了，裂开了，绷不住了 | 由社交媒体版按平台语域处理；包袱版本身不产出伪反应 |
| J12 | 刻意搞笑、每句带梗 | 今天天气真好——好到我怀疑太阳也加班了；我出门了——出门这个词本身就很有哲学意味…… | 幽默是蛋糕上的樱桃不是主食；做减法 |
| J13 | 结构正确但不好笑（老梗冷笑话） | Oct 31 = Dec 25 式的冷笑话，讲完空气安静 | 与场景 2 的原创冷笑话区别在两点：这是被讲滥的老梗，且与在场者的真实生活无关。幽默需要「共谋」——无语式幽默成立的前提是梗还新鲜、场景还具体 |
| J14 | 踩红线还以为是幽默 | 拿地震幸存者、职业、外貌开涮 | 攻击方向检查：自嘲 > punching up > punching down 禁止 |
| J15 | 种了种子不收割 | 开头埋了「我爸的假发」，后面再没提 | 种了种子就要收割；callback 要不经意埋、突然 call |

### 5.2 好包袱四判据

1. **意外性**：打破已建立的预期（康德「期望突然变成虚无」；林语堂「预期的逆应」）。
2. **合理性**：转折「和观众刚听到的一切仍然对得上」；荒谬须有内部逻辑。
3. **简洁性**：铺垫短而像真话；Tag 越短越快；揭底后闭嘴。
4. **节奏**：停顿、冷脸、语速反差、顿跌；「铺垫越正经，反转越炸」。

### 5.3 技法库

- **相声**：铺平垫稳、三翻四抖（「三」为虚指）、迟疾顿挫、现挂/砸挂、侯宝林直接法（重复/机辩/夸张/否定/矛盾）与间接法（曲解/双关/错觉/误会/映衬/对照/假托/道反/譬喻/假借）、马季 22 法。
- **脱口秀**：premise、setup、punchline、tag、rule of three、callback、one-liner、deadpan。
- **小品/情景喜剧**：setup → escalation → payoff、反差/重复/巧合、running gag、伏笔回收、「Don't go past the joke」、topper 最多两次。
- **书面幽默**：靠标点、分段、换行制造视觉停顿；允许「走神儿」（口语反对走神）。
- **冷笑话 / 无语式幽默**（合法笑法，不是 J8 病灶）：正经铺垫 + 荒谬揭底 + 尬到无语。不止谐音一种，还包括叙事反转、一本正经的荒谬解释、废话重复、命名双关（范本见场景 2）。「尬」是预期效果——听者先无语，再无语地笑。判据是「无语地笑」还是「单纯尴尬」。

### 5.4 红线（不可抖包袱处）

- **攻击方向**：自嘲（安全）＞ punching up（吐槽权威/制度/甲方）＞ punching down（绝对禁止：弱势、贫困、残障、外貌、受害者）。
- **灾难与逝者**：地震、恐袭、战争、灾难牺牲者——不拿它们抖包袱。
- **歧视**：地域、性别、民族、人种、职业的俯视式刻板印象。
- **低俗**：理想状态是「包袱在触线前一毫米躲开」，过线即不雅。
- **场合**：悲伤/严肃讨论中插科打诨；正式语境用「草」「2333」等网络反应词。
- **老梗反刍**：谐音梗技术含量低、不具新颖性，「说了一半旁人就能猜到后半句」。
- **笑点植入广告**：为抖包袱植入商业信息会翻车（笑点服务说服，不能压过卖点）。
- **验收标准**：只有被开玩笑的人也笑了才叫幽默，否则是霸凌。

## 六、与通用版的差异

| 维度 | 通用版 | 包袱版 |
|------|--------|--------|
| 目标 | 去 AI 腔，像人说话 | 造笑点，该笑的地方真的笑 |
| 原则 | 意思不变，话变 | 意思不变、动机不变、红线不破，笑点结构重建 |
| 工作流 | 标记→初稿→核对→终稿 | 同四步；核对步增加「人物动机 + 红线」检查 |
| 写作样本 | 匹配句长用词标点 | 升级为「喜剧人声口 / 人物固定笑法」 |
| 防误伤 | 防误伤原意 | 双重：防误伤原意 + 防误伤红线对象 |
| 判定标准 | 读起来像人话吗 | 响包袱还是闷包袱？意料之外、情理之中？ |
| 输出 | 默认只给终稿 | 终稿 + 节奏标记（书面用标点分段，口头用气口提示） |

**与其他扩展版的分工**：

| 版本 | 分工 |
|------|------|
| 学术版 | 包袱版不碰学术伦理与引用；学术文本里的幽默需学术版先过规范 |
| 营销版 | 幽默广告：包袱版管笑点成立，营销版管说服与广告法；笑点不得压过卖点 |
| 文学创作版 | 文学喜剧交界带：包袱版定笑点结构，文学版润质感；文学版管「美不美」，包袱版管「笑不笑」 |
| 社交媒体版 | 包袱版产笑话内核，社媒版做平台语域封装（梗、反应词、标签、篇幅）——内核不成立，封装再好也尬 |

## 七、扩展边界

**本版负责**：包袱诊断、结构重构、节奏标记、载体适配、人设守门、红线检查、老梗识别。

**本版不做**：
- 不负责通用语言层 AI 腔（升华式对比、口号结尾、机械连接词）——通用版
- 不负责平台语域封装——社交媒体版
- 不负责文学质感润色——文学创作版
- 不负责广告法合规审查——营销版
- 不负责学术规范——学术版
- 不写歧视、灾难、低俗内容；不做评论水军

**移交规则**：笑话内核成立后再交给社交媒体版封装；文学喜剧先由本版定结构、再由文学版润质感；幽默广告由本版诊断笑点、营销版把关卖点与合规。

## 八、典型使用场景与期望输出示例

### 场景 1：解释笑话

**输入**：
> 我昨天跟老板说我想努力工作，但我的老板不配。我这句话的意思其实是，我用一种幽默的反讽方式表达了我对职场现状的不满，希望大家能理解我的处境。

**期望输出**：
> 我也想努力工作啊……但我的老板不配。

**说明**：删解释（J1），保留铺垫的「大实话」语气，揭底即止，给出停顿标记。

### 场景 2：冷笑话与破谐音（无语式幽默）—— 不改，且要认出它是对的包袱

这是 J8 的**反面样例**，用来防止误伤。破谐音梗（冷笑话）的笑点机制不是「两层语义都成立」，而是**正经铺垫 + 荒谬揭底 + 尬到无语**。听者先是无语，然后无语地笑——「尬」是预期效果，不是失败。

无语式幽默不止谐音一种，常见五种风格：

| 风格 | 范本 | 笑点机制 |
|------|------|----------|
| 问答谐音 | 什么动物最容易摔倒？狐狸，因为它很狡猾（脚滑）。 | 问句一本正经，答案自信满满，谐音破得让人扶额 |
| 叙事反转 | 小白兔去面包店问有没有一百个小面包，老板说没有。第二天又问，还是没有。第三天老板连夜烤了一百个。小白兔来了：有一百个吗？有！太好了，给我来两个。 | 老板的辛苦铺垫全部落空，落差带来无语 |
| 一本正经的荒谬 | 为什么企鹅肚子是白的？因为手太短，洗不到后背。 | 用严肃的解释腔讲一个不成立的原因 |
| 废话重复 | 听君一席话，如听一席话。 | 期待有洞见，结果原地踏步；「重复的笑点在于差异」的极端形态 |
| 命名双关 | 我养了一只鸭子，它特别凶，我叫它「鸭力山大」。 | 人名与鸭名强行合一，揭底一本正经 |

共同点：铺垫短、揭底正经、逻辑荒谬但自洽。**尬都在，但正因为尬才响。**

**输入**：
> 我养了一只鸭子，它特别凶，我叫它「鸭力山大」。

**期望输出**：
> 原样保留，不改。

**说明**：这句有完整的无语式结构——铺垫（养鸭、凶）足够短且像真话，揭底（鸭力山大）一本正经，谐音的尬正是笑点。若按「双层语义要成立」硬改成所谓高级双关，反而会造出更尬的句子——那就真成了 J12（刻意搞笑）。判据：**听者是无语地笑，还是单纯尴尬？前者是响包袱，后者才是 J8 病灶。**

**什么才是真 J8**：不在冷笑话语境里、没有无语效果、纯粹为谐音而谐音的硬塞。例如正经的产品发布会上突然来一句「我们这款产品特别鸭力山大」——既非设问、也无荒谬逻辑，只是把梗塞错地方。

### 场景 3：剧情包袱

**输入**：
> 小品里，一个全程斯文、说话轻声细语的会计，突然在饭桌上拍案大喊：「我就是个废物哈哈哈！」全场大笑。

**期望输出**：
> 诊断：人物为抖包袱行为失真（J10）。斯文会计的笑法应该是「过度精确」——比如被问欠多少钱，他掏出计算器按了半天，报出「三千七百二十一块四毛」，然后补一句「四毛不能少」。
> 若要保留拍案，须先铺垫：前面埋他曾被同行用「四舍五入」坑过一次（种种子），拍案时才收割（callback），且动作幅度仍应克制。

### 场景 4：踩红线拒绝

**输入**：
> 帮我写个段子，拿某地地震幸存者和他们住的板房开玩笑，越损越好笑。

**期望输出**：
> 无法执行：拿灾难幸存者开玩笑违反本版红线（攻击方向矩阵禁止 punching down，且灾难与逝者不可抖包袱）。可以做的是：① 自嘲式段子；② 吐槽权力结构或社会荒诞的段子（punching up）；③ 如果你真的经历过那场地震并想以「悲剧+时间距离」的方式写反思，说明你的意图和距离，我们谨慎处理。
> 验收标准：只有被开玩笑的人也笑了才叫幽默。
