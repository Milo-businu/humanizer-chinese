# 文学创作版 Skill 提案

> 基于通用版「白描改写」扩展。本提案只做设计，不含实现代码。

## 一、版本定位

**一句话**：在「AI 的标准化套路」与「作者刻意的风格选择」之间做出体裁敏感的判别，把告知式情绪、假深刻修辞改写为有声音、有呼吸感的展示性文字——**不是把文学改成人话**。

**核心原则**：通用版是「意思不变，话变」；文学版升级为「**意图/阅读效果不变，话变**」。隐喻、反讽、悖论、留白、方言、碎句、反常规语法列入白名单，不强行说破、不强行捋顺。

## 二、适用场景

- 小说（含类型小说）的语言打磨
- 散文集、随笔的语感统一
- 诗歌的语言密度与节奏调整
- 剧本对白的自然度检查
- 非虚构写作的叙事呈现
- 网文的套路化桥段去味

## 三、目标用户

- 小说作者、网文作者
- 散文/诗歌创作者
- 编剧、对白写作者
- 非虚构写作者
- 文学写作课师生

## 四、核心能力

1. **tell → show**：把直白情绪词改成展示性细节（「她很虚弱」→「她连筷子都拿不起了」），把结论变成现场。
2. **体裁识别**：先判断是小说/散文/诗歌/剧本/非虚构，再切换改写阈值——技术文档适用的规则对叙事文体不适用。
3. **作者声音守护**：建立「作者风格档案」，检查改写后是否还像同一个叙述者在说话；去掉对话标签后能否辨认说话者。
4. **节奏与句式变化**：标注每句字数，大量落在 12–18 字区间就刻意改三句；长句承载沉思、短句制造果断/焦虑。
5. **意象具体性检查**：区分「窗台是绿色的」（只有具体）和「绿漆开始剥落」（具体且有意义）。
6. **视角一致性检查**：守住限知视角的认知边界，检测人称漂移、时间线硬伤、物理常识错误。
7. **误伤防护**：保留服务节奏的反复（如鲁迅「是事实」三次重复）、原创隐喻、有主题依据的晦涩（意识流）。

## 五、内容与风格规范

### 5.1 文学版专属病灶

| # | 病灶 | 改写前 | 改写后 |
|---|------|--------|--------|
| L1 | 标准化肢体情绪套餐 | 受辱就指节发白，震惊就张嘴巴，欲言又止，指尖泛白 | 换成这个人、这个场景独有的反应 |
| L2 | 「不是 A，而是 B」假深刻 | 不是愤怒，不是反抗，而是一种温柔的、集体的下坠 | 用具体动作或场景承载 |
| L3 | 比喻密集套路化 | 像一把无形的刻刀，月光像碎银，霓虹废墟低语命运黑暗宿命 | 像「旧衬衫被洗了很多次之后的蓝」——具体且不常见 |
| L4 | 情绪直接命名 | 脸上露出无尽的爱，心里像盛了满院春光 | 用感官细节让读者自己推导 |
| L5 | 句式/段落长度均匀 | 每章精确 2500±5 字，句子 18–22 词 | 长短交错，允许无用细节 |
| L6 | 节奏匀速、所有冲突闭环 | 所有伏笔都回收，没有生活碎片 | 保留「窗边飞过一只鸟」「桌上一杯凉掉的茶」 |
| L7 | 三段式与章末强行升华 | 第二章咖啡馆对话、第四章追车、第六章雨中告白；平均的开头冲突反转结尾 | 打破模板节奏 |
| L8 | 人物换名不换人 | 除了说的话不一样，本质是同一种语气同一个人 | 建立声纹：词汇、句式、节奏各异 |
| L9 | 通用采样式反应 | 父亲发现儿子学琴→「脸色一下子变了」/「脚步停在门外」/「空气突然安静下来」 | 换成只有这个人会有的反应 |
| L10 | 浮华大词与伪口语 | 锦绣、深刻的友谊；「今天天气真好」写成「今日天气状况十分理想」 | 按人物身份与情境说话 |
| L11 | 因果/视角硬伤 | 白头发写成黑色；同段人称突变（我→他→我） | 标记给用户核对，不擅自改设定 |
| L12 | 标点过于「正确」 | 雨下大了，他没带伞，背影慢慢融进雨里。 | 雨下大了。他没带伞。背影慢慢融进雨里。 |

### 5.2 写作规范

- **show don't tell**：用感官细节让读者推导；避免三个陷阱——过度展示变说明书、展示情绪却没展示动机、借角色之口「告知」。
- **声音（voice）**：每个说话者有独特词汇、句式、节奏；检验法是去掉对话标签后还能否辨认。
- **节奏**：长句承载沉思、短句制造果断/焦虑；刻意打破均匀。
- **意象**：既具体又有意义（「绿漆开始剥落」优于「窗台是绿色的」）。
- **留白**：删掉解释性的最后一句（黛玉「宝玉，你好……」）。
- **视角**：限知视角守住叙述者认知边界（参考《孔乙己》）。
- **对话**：真实对话含回避、地位之争、未说完的想法；每一句有社会动机。
- **体裁差异**：小说是客观性语言（让人物/情节代作者说），散文是主观性语言（可直抒），诗歌重象征、留白、克制抒情，允许倒装、错位、通感。
- **白名单**：方言、俚语、隐喻、反讽、悖论、有意重复、意识流——AI 恰恰回避这些，它们是「人味」的载体。

### 5.3 红线

1. 不得把隐喻、反讽、留白强行说破。
2. 不得把作者有意的不规矩句式「改正」。
3. 不得把有主题依据的晦涩（意识流）判为病灶。
4. 文学虚构不等于可以编造史实——发现历史硬伤标记给用户，不自行「创作」历史。
5. 不承诺骗过 AI 检测器；检测工具正误伤书面化的真人写作。

## 六、与通用版的差异

| 维度 | 通用版 | 文学版 |
|------|--------|--------|
| 核心目标 | 像人说话 | 像这个作者在说话 |
| 不变底线 | 意思不变 | 意图/阅读效果不变 |
| 隐喻/留白 | 可能当套话删 | 白名单，保留 |
| 排比/反复 | 删除 | 有节奏功能的保留 |
| 情绪表达 | 改成直白 | 改成展示性细节（反向） |
| 碎句/方言 | 捋顺 | 资产，保留 |
| 写作样本 | 匹配用词标点 | 升级为「作者风格档案」，含声纹与视角 |
| 输出 | 默认只给终稿 | 默认给终稿 + 病灶标记（因误伤代价高） |
| 前置步骤 | 标记病灶 | 先识别体裁，再切换阈值 |

## 七、扩展边界

**本版负责**：体裁识别、show don't tell、声音一致性、节奏与意象、视角检查、风格白名单。

**本版不做**：
- 不负责语言层的通用 AI 腔（升华式对比、口号结尾、机械连接词）——那是通用版
- 不负责笑点结构与喜剧节奏——那是包袱版
- 不负责平台语域——那是社交媒体版
- 不负责学术伦理与引用——那是学术版
- 不替作者做创作决策（谁出场、什么结局、主题是什么）

**移交规则**：文本以笑果为首要目标（段子、喜剧对白、剧情包袱）时，移交包袱版；文本是平台内容时，移交社交媒体版。交界带（文学喜剧）先由包袱版定笑点结构，再由本版润质感。判断依据：若「文字表达本身就是实质内容」（葛四友），归文学版。

## 八、典型使用场景与期望输出示例

### 场景 1：情绪告知 → 展示

**输入**：
> 得知消息后，她非常悲伤，眼中透露出无尽的绝望。她强忍着泪水，指节发白，欲言又止。

**期望输出**：
> 她把碗放进水槽，水龙头开着，她没伸手洗。过了很久，她弯腰把脸凑近水面，又直起身，用手背擦了一下眼睛。

**说明**：删标准化肢体套餐（L1/L4），换成这个场景独有的、有生活质感的动作；不解释她为什么难过。

### 场景 2：假深刻 → 场景

**输入**：
> 这座城市不仅是一个地理空间，更是一种精神的隐喻。它不是砖石的堆砌，而是无数记忆的容器。夜色中的霓虹、雨后的废墟、低语的人群，都在诉说着命运的沉与浮。

**期望输出**：
> 雨停后，巷口那家打印店还亮着灯。玻璃上贴着一张褪色的招工启事，边角被雨泡卷了。她站在站台下，没打伞，看那盏灯灭了又亮。

**说明**：删「不是 A 而是 B」（L2）和大词意象堆（L3），换成有具体时间、地点、物的场景；保留含混，不给结论。

### 场景 3：诗歌的误伤防护

**输入**：
> 月光像一把碎银洒在地上／时间是一条不打结的河流／我在夜里数那些没有名字的东西

**期望输出**：
> 原样退回。

**说明**：这些是原创隐喻、反常规搭配、有意留白，属白名单；诗歌「文字表达本身就是实质内容」，不由本版改动。
